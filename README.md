# Business System - CRM, Store, GPS, Nova Poshta

This repository contains the architecture specification and initial database
schema for a production-ready business system with:
- CRM and Kanban automation
- Online store and order management
- Manager and client mobile apps
- GPS tracking and geofencing
- Nova Poshta integration

Primary documents:
- architecture.md - full system architecture and implementation plan
- schema.sql - PostgreSQL DDL schema for core modules
